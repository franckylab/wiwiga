2 · Best practices — 3D jeton / casino chip (web & Flutter)

Géométrie

Volume crédible = 4 couches

  • Face (top/bottom) — métal + dégradé radial + inner ring + insert.
  • Chanfrein (bevel) — anneau 6–8% du rayon, highlight spéculaire en haut, ombre en bas.
  • Tranche (edge) — hauteur 14–18% du diamètre; hachures/milling optionnel; couleur métal plus sombre.
  • Ombre portée — ellipse floutée, opacité 22–30%, blur = 22–36% du diamètre.

Réf. iStock jeton casino: insert en croix/damier, bord pointillé, tranche striée. Best practice CSS 2025: empiler translateZ (12–24 layers) OU simuler via conic-gradient + radial-gradient pour perf mobile. Voir DEV deep-dive "Build a 3D Flipping Coin" (preserve-3d, backface-visibility).

Rendu

Matière & lumière

  • PBR simplifié: base color + highlight (60% white, 18% size, offset -22%) + rim light (cyan/emerald .35).
  • Gradients: radial 0→70% (clair) puis 70→100% (foncé) pour bombé; conic pour reflets tournants.
  • Métaux: Émeraude (WIWIGA), Or (#FFD700), Argent (#C0C0C0), Bronze (#CD7F32), Diamant (holographic).
  • Texte W: emboss (ombre portée 1px + inner highlight) — lisible dès 20 px.

Éviter box-shadow lourd en liste. Préférer filter: drop-shadow sur le conteneur 3D. Sur Flutter: MaskFilter.blur + RadialGradient + LinearGradient pour tranche.

Performance

Animateur = GPU only

  • Animer uniquement transform et opacity. Jamais width/height/top/left.
  • will-change: transform seulement pendant l'animation; retirer après.
  • translate3d(0,0,0) ou translateZ(0) pour promouvoir en layer GPU (mobile).
  • prefers-reduced-motion: désactiver spin/auto-flip; garder fade.
  • Flutter: envelopper animé dans RepaintBoundary + AnimatedBuilder + shouldRepaint fin.

Sources: Lexo will-change 2025, Unwired GPU Transforms 2026, Flutter Effective Animations (RepaintBoundary, FragmentShader).

Accessibilité & sémantique

  • role="img" aria-label="Jeton WIWIGA — 1 000 jetons" sur chaque pièce significative (pas sur les inline décoratifs → aria-hidden).
  • Contraste texte W ≥ 4.5:1 (blanc sur émeraude/or OK; prévoir outline sombre en variante claire).
  • Zone tactile ≥ 44×44 px; espacement 8 px entre chips cliquables.
  • Motion: @media (prefers-reduced-motion: reduce) → stop rotations; garder pulse lent (2.4s).

Responsive — règle d'or

  • ≤ 20 px (inline): 2D flat, 1 couleur + glow minimal. Pas de tranche.
  • 24–48 px (chips, header): 2.5D — face + bevel + ombre; tranche 1–2 px via border/shadow.
  • ≥ 56 px (hero, victoire, pack): full 3D — face + bevel + tranche épaisse + reflet spéculaire + ombre portée.
  • Adapter via clamp() et breakpoints WIWIGA: xs 0–359, sm 360–599, md 600–899, lg 900–1199, xl 1200–1599, xxl 1600+.

7 · Effets & animations — par contexte (quoi, quand, comment)

Subtil (tout le temps)

Pulse glow — header solde

Opacity 0.30 → 0.58 → 0.30 sur 2s, easeInOut, infinite. Sur box-shadow uniquement (GPU). Pause si prefers-reduced-motion.

Pulse 2s
Idle (ref)

BoxShadow(color: primary.withOpacity(anim), blurRadius: 8→14)

Événement (au tap)

Flip + scale — chips mise

Au tap preset: scale 1.0→1.08 (120ms) + rotateY 0→180° (420ms) pour révéler tranche/verso, puis retour. Haptic lightImpact.

Célébration

Spin + confetti — victoire

Gain: rotateY 0→720° (900ms, easeOutCubic) + scale 0.9→1.08→1.0 + particules confetti (6–10 dots, 600ms). Son optionnel.

Pot

Drop + stack — mise dans pot

Quand un joueur mise: pièce tombe (translateY -40→0 + rotateZ 8°→0, 380ms) et s'empile. Ombre s'épaissit à chaque jeton.

Shimmer

Balayage — boutique / podium

Bande blanche 18% largeur, translateX -120%→220% en 1.1s, opacity .0→.28→.0, skewX 12°. Se déclenche au hover ou toutes les 4s.

Accessibilité

Reduced motion

@media (prefers-reduced-motion: reduce) → désactive spin/flip/drop; garde opacity fade 200ms + pulse très lent (3.2s). Flutter: MediaQuery.disableAnimations.

9 · Plan d'implémentation Flutter — CustomPainter 3D

Architecture painter (LOD auto)

// token_coin.dart — structure recommandée
class TokenCoin extends StatelessWidget {
  final double size;
  final TokenVariant variant; // emerald/gold/silver/bronze/diamond/holo
  final TokenLod lod;         // auto/flat/bevel/edge/full
  final TokenEffect effect;
  // ...
}

class _TokenCoinPainter extends CustomPainter {
  void paint(Canvas canvas, Size size) {
    final r = size.width/2;
    final lod = _resolveLod(size.width); // 16→flat, 24→bevel, 44→edge, 96→full

    // 1. Ombre portée (ellipse)
    if (lod != Lod.flat) _drawShadow(canvas, r);

    // 2. Tranche (edge) — si lod ≥ edge
    if (lod.index >= Lod.edge.index) _drawEdge(canvas, r);

    // 3. Face — radial gradient + inner ring
    _drawFace(canvas, r, variant);

    // 4. Bevel — si lod ≥ bevel
    if (lod.index >= Lod.bevel.index) _drawBevel(canvas, r);

    // 5. Insert (damier or) — si variant gold & lod ≥ edge
    if (variant==gold && lod.index>=Lod.edge.index) _drawInsert(canvas, r);

    // 6. W emboss
    _drawW(canvas, r, lod);

    // 7. Spéculaire (highlight)
    if (lod.index >= Lod.bevel.index) _drawSpecular(canvas, r);
  }
}

Gradients Flutter: RadialGradient pour bombé, SweepGradient (conic) pour holographic, LinearGradient pour tranche. Highlight via RadialGradient(center: Alignment(-0.3,-0.4)).

Animations — GPU only

// Effets animés — envelopper dans RepaintBoundary
class _AnimatedTokenCoin extends StatefulWidget { ... }

10 · Risques, limites & garde-fous

Risques

  • Surcharge visuelle si 3D partout → bruit, perte hiérarchie.
  • Perf mobile si conic/shadow en liste longue (100+ tx).
  • Lisibilité W à 14 px si stroke trop fin.
  • Incohérence si plusieurs géométries coexistent (rond vs hexagone).

Limites assumées

  • Pas de vraie 3D WebGL — simulation via gradients (choix perf).
  • Tranche hachurée simplifiée (pas de milling photo-réaliste).
  • Holographic via SweepGradient (pas de vrai shader PBR).
  • Pas de rendu côté serveur — tout est client Flutter.

Garde-fous

  • LOD auto + flat en liste.
  • Alias TokenIcon → 0 breaking.
  • Golden tests à 16/44/120 px.
  • Semantics + prefers-reduced-motion systématiques.
  • Review design à chaque LOD.

Checklist de validation avant merge

  • ☐ Rendu à 16, 24, 44, 72, 120 px sur xs/sm/md/lg/xl
  • ☐ Contraste W ≥ 4.5:1 (toutes variantes)
  • ☐ Zone tactile ≥ 44×44 sur chips
  • ☐ Aucun jank >16ms (profile, 60fps)
  • ☐ RepaintBoundary sur animés
  • ☐ prefers-reduced-motion testé
  • ☐ TalkBack / VoiceOver lit "X jetons"
  • ☐ Pas de 3D en liste transactions (flat)
  • ☐ Alias TokenIcon fonctionne
  • ☐ Goldens verts (CI)
