Recherche — best practices 2025-2026 (synthèse)

Sources croisées : LogRocket, UIXplor, Eleken, SVGator, MagicUI, NN/g, Beetlebeetle — + guidelines Flutter/Lottie.

01 — Skeleton > Spinner pour contenu

Skeleton mimic le layout final → perception +40% plus rapide. Spinner réservé aux tâches courtes sans structure (bouton, action).

  • Garder layout identique au final, sinon confusion.
  • Shimmer subtil transform: translateX uniquement (GPU).

02 — Logo loader = branding

Splash <2s : logo animé = premier contact marque, vu des centaines de fois → mémorisation ultra.

  • Tracé stroke-dasharray + pulse sobre > rotation agressive.
  • SVG natif, pas de JS lourd, Lottie JSON optionnel.

03 — Performance 2025

N’animer que transform + opacity — GPU, pas de reflow.

  • linear pour spin (stable), ease-in-out pour pulse.
  • will-change: transform avec parcimonie, prefers-reduced-motion: reduce → none.

04 — Durée & easing

Spin 0.8–1.0s linéaire (mécanique), pulse 1.6–1.8s ease-in-out (respiration), trace 1.4–1.6s ease-in-out.

  • Trop rapide = stress, trop lent = lag perçu.
  • Boucle sans à-coup (seamless).

05 — Contexte = choix du loader

Pas 1 loader partout. Système responsive :

  • Splash 100 : logo tracé + progress
  • Overlay 48 : logo pulse/orbit
  • Inline 20 : dot/pulse minimal
  • Skeleton : grille/carte

06 — Sobre = premium 2026

Tendance “Minimalist & Lightweight” — trait fin, 1 couleur #2DD4BF, pas de gradient, pas de glow cheap.

  • 1 idée, 1 trait, 1 easing — “less but better” (Braun).
  • Accessibilité : contraste + aria-busy, pas d’animation bloquante.
