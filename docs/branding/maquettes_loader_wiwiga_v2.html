Cadre — lumière multicolor infinie

Trait lumineux 40px + 320px vide qui parcourt le squircle rx24 en boucle linear 1.5–1.9s. Sans fin, sans à-coup (stroke-dashoffset -360).

  • Sobre : 1 lumière → 2 lumières max, pas 10.
  • Multicolor : gradient #2DD4BF → #00D9FF → #F59E0B → #A78BFA via url(#grad), hue discret.
  • GPU : stroke-dashoffset + transform uniquement.

W — cœur battant (zoom)

Scale 1 → 1.14 → 1 → 1.14 → 1 (heartBeat 0.9–1.05s ease-in-out). Variante double battement heartDouble (comme un vrai cœur : 1.16 → 0.96 → 1.16).

  • Origine 50% 50%, pas de déplacement, juste zoom.
  • Avec cadre ou sans cadre — le W bat seul.
  • Respect prefers-reduced-motion → scale figé à 1.
